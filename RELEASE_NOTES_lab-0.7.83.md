- Micrófono opcional para juegos compatibles. Actívalo en Ajustes para la siguiente partida y usa □ en el menú táctil para silenciarlo o reactivarlo.

## English

- Optional microphone for compatible games. Enable it in Settings for the next session and use Square in the touch menu to mute or unmute it.
- Lab can compare 10 and 20 ms voice frames, display the input level in the HUD and log capture, send and RTCP metrics.
- The cloud gaming timer is hidden when Xbox returns an inconsistent finite balance.
