# User interface

`canvas.c` draws rectangles and a pixel alphabet created for XCloud4. `screen.c` presents the home, controller, project, local media, Microsoft account, Xbox catalog and session views.

The PS4 interface remains Spanish at the owner's request. English repository documentation does not change its displayed text. Account, catalog and session authorization are confirmed through version 0.6.2; actual game video/audio is still the next milestone.
